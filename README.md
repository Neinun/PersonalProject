# Casio Retro Personal Portfolio

A retro-futuristic, Casio digital watch & Nokia Lumia / Windows 8 Metro-inspired personal portfolio website for **Sumit Kumar Singh**.

## Features

- **Casio Retro Aesthetics**: Paper textures (`#EDDFC6` Vintage Cream), brutalist offset hard shadows, Share Tech Mono & VT323 typography.
- **Nokia Lumia / Windows 8 Metro Live Tiles**: 3D vertical flipping tiles (`rotateX(180deg)`), background cycle rotation, tactile click-to-flip.
- **Synthesized 8-Bit Audio**: Web Audio API tactile sound synthesis with sound toggle control.
- **Live LCD Clock**: Synchronized digital clock module with day and date indicators.
- **Interactive Stopwatch**: Casio Module 280 digital timer with lap/reset precision.
- **Projects & Experience**: Shipped project cards and comprehensive professional experience timeline.
- **Zero Emojis**: Clean monospace and ASCII retro design.

## Media Setup

Place the following local media assets in the root directory if running locally:
- `profile_image.jpeg` — Profile portrait image
- `Mulsy.png` — Mulsy project logo
- `iim_trichy_video.webm` — IIM Trichy campus video
- `route_vid.webm` — CRT route stream video
